# E-Commerce Product Management System

A simple console-based E-Commerce Product Management System developed using **Java**. This project helps manage product information, search products, sort products by price, and update stock details.

## Features

- Add new products
- View all available products
- Search products by Product ID or Category
- Sort products by price (Low to High)
- Update product stock
- Automatically generate unique Product IDs
- Save and load product data using a text file

## Technologies Used

- Java
- HashMap
- ArrayList
- File Handling
- VS Code

## Project Structure

```text
ECommerce-Product-Management-System/
│
├── Main.java
├── products.txt
└── README.md
```

## How to Run

1. Install Java JDK 17 or above.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Compile the program:

```bash
javac Main.java
```

5. Run the program:

```bash
java Main
```

## Data Structures Used

| Data Structure | Purpose |
|---|---|
| HashMap | Stores products using Product ID |
| ArrayList | Stores products for price sorting |

## Project Objective

The objective of this project is to understand how Java data structures and file handling can be used to build a basic product management application.
